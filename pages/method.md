# Method

## Why

We want a pool of recent multi-agent LLM papers to choose from, without picking by hand or by hype. The list is built by a pipeline so that it can be rebuilt and extended.

## First seen

Papers are first seen in the proceedings of major AI, NLP and human–computer interaction conferences. We collect each paper's title and abstract from the bibliography and proceedings sources, and its full text where one is openly available.

## The matching system

1. **Screen.** A language model reads each abstract and keeps the papers that look like they study several LLM agents working together.
2. **Read.** A stronger language model reads the full text of the kept papers, confirms that they really are multi-agent LLM systems, and tags each paper (its purpose, whether the agents cooperate or compete, how they are structured, and which design or social factors it deals with).
3. **Publish.** The confirmed papers become the list on the front page.

The tags are generated by a model, so use them to find papers and check the abstract before relying on one.
