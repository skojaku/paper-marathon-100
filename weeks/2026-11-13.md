## Adaptive Theory of Mind for LLM-based Multi-Agent Coordination

Mu et al., AAAI 2026 (Multiagent Systems track).

### Summary

Theory of mind (ToM) is the ability to reason about what others believe and intend. Higher-order ToM adds that the other also reasons about you. Earlier work equipped LLM agents with ToM to help them coordinate. This paper adds a finding: when two agents reason at different depths, or at the same depth, coordination can get worse. It calls this misaligned ToM order.

Setup:

- Two agents in a fully cooperative problem with a shared state and a shared reward. Both receive the same reward, so the reward measures the pair, not either agent.
- A policy is a table from states to action probabilities. The paper uses Q-values from reinforcement learning without explaining them.
- A ToM-K agent assumes its partner reasons at order K−1 and picks the action that is best against that partner. Orders are limited to 0, 1 and 2. The paper cites studies that find people rarely reason deeper than second order.
- The paper states that an agent at order K coordinates best with partners at K−1 or K+1, and worse with partners at the same order.

The method is an adaptive ToM agent (A-ToM). It keeps one hypothesis for each order, estimates from past interactions which order the partner uses, and acts on the matching hypothesis. It has two ways to update: follow-the-leader (commit to the best-matching order) and Hedge (keep weights over all orders).

Tasks, four in total:

- **Repeated matrix game.** Both agents pick A or B at once. Same choice pays 0, different choices pay 5 each, so the agents must break the symmetry. Run with memory of the partner's last action, and with counts of the partner's past actions.
- **Two grid navigation tasks.** Each agent must reach its own target without colliding. Measured in time.
- **Overcooked.** Two cooks make and deliver onion soup in a shared kitchen. Measured in time.

Results:

- Coordination is best when the agents' orders are aligned in the paper's sense, that is, different in the right way.
- With counts as memory, misaligned pairs also do fine. Two ToM-0 agents fail by alternating between the same two options, and random variation eventually breaks the tie.
- Against partners with a fixed order, follow-the-leader is slightly better than Hedge, probably because it identifies the partner's order faster. In self-play, Hedge is clearly better, especially in the matrix game and grid navigation. The paper attributes this to Hedge exploring more.
- In the case study, the A-ToM agent's weights settle on the partner's true order within the first few steps.
- The paper also discusses when ToM alignment matters less, and applies A-ToM to agents that are not LLM-based.

### Questions

- **Why would agents of the same order coordinate badly "naturally"?** The paper states this without a derivation. The answer in the room: if both agents reason at the same order, they predict each other the same way and choose the same action. In a task that rewards different actions, that pays nothing. The assumption follows from the recursive structure, since an agent at order K models its partner at K−1. The cited studies are social-science results that support only the limit of order 2. The conclusion that same-order pairs fail therefore holds for tasks where different roles pay, and the paper does not say which tasks those are.
- **Is choosing the same action a conflict?** Not by itself. It is redundancy: if every agent does the same minor sub-task, the overall goal is not reached. Whether this matters depends on how the task is structured.
- **Does more diversity mean better cooperation?** A class of 30 people all giving different answers has maximal diversity and is not good cooperation. The point of the setup is complementary actions toward one shared goal, not disagreement. The paper should state the task structure under which different orders help.
- **Does breaking symmetry show that two agents understand each other?** It is one measure. The paper argues for alignment as a necessary factor for coordination, and the tasks are chosen so that this factor matters. One view was that a single variable cannot evaluate collaboration.
- **What does "aligned" mean in the results table?** It is not defined in the text. It was read as the pair holding orders that complement each other. The table mixes points and time across tasks, and the labels (memory one, memory N, game one, game two) made it hard to read.
- **Are the tasks too game-like?** Small games are a common abstraction in social science because they are easy to interpret and have few parameters. They are not evidence about realistic tasks such as several agents writing software together.

## Open questions

- Under what task structure do agents of different ToM orders coordinate better than agents of the same order?
- Does the result carry over to tasks where the partner's order is not one of three fixed levels?
- Does ToM alignment still matter when agents can communicate in natural language?
- How should coordination be measured when the metric is points in one task and time in another?
